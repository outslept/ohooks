The `useThrottleCallback` hook returns a stable, throttled version of a callback that executes at most once per `wait` milliseconds, supporting `leading` and `trailing` execution edges as well as `.cancel()`, `.flush()`, and `.isPending()` controls.

## Installation

<HookInstallation name="useThrottleCallback" />

## Usage

```tsx
import { useThrottleCallback } from "@/hooks/useThrottleCallback";
```

```tsx
const handleScroll = useThrottleCallback((scrollY: number) => {
  saveScrollPosition(scrollY);
}, 200);
```

## Examples

### Throttling Window or Container Events

Limit how frequently an expensive handler runs during continuous scroll or resize events.

```tsx
const logScroll = useThrottleCallback(
  (top: number) => {
    reportScrollAnalytics(top);
  },
  500,
  { leading: true, trailing: true },
);

return (
  <div
    onScroll={(e) => logScroll(e.currentTarget.scrollTop)}
    style={{ height: 200, overflowY: "auto" }}
  ></div>
);
```

### Flushing or Cancelling a Trailing Call

Use `.flush()` to immediately run a pending trailing invocation or `.cancel()` to discard it.

```tsx
const throttledSave = useThrottleCallback((draft: string) => {
  api.save(draft);
}, 1000);

return (
  <div>
    <textarea onChange={(e) => throttledSave(e.target.value)} />
    <button onClick={() => throttledSave.flush()}>Save immediately</button>
    <button onClick={() => throttledSave.cancel()}>Cancel pending</button>
  </div>
);
```
