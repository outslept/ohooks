<HookPreview name="useDropZone" />

The `useDropZone` hook manages drag-and-drop file uploads, tracks nested drag-enter depth so `isOver` does not flicker over child elements, and filters dropped files by MIME type or file extension.

## Installation

<HookInstallation name="useDropZone" />

## Usage

```tsx
import { useDropZone } from "@/hooks/useDropZone"
```

```tsx
const { isOver, files, getRootProps } = useDropZone({
  accept: "image/*",
  onDrop: (accepted) => console.log(accepted),
})
```

## Examples

### Drop Zone with `getRootProps`

Spread `getRootProps()` onto your container element when you do not already have a separate `RefObject`.

```tsx
const { isOver, files, getRootProps } = useDropZone({
  accept: ["image/*", ".pdf"],
  multiple: true,
  onDrop: (accepted, rejected) => {
    console.log("Accepted:", accepted, "Rejected:", rejected)
  },
})

return (
  <div
    {...getRootProps()}
    style={{
      border: isOver ? "2px solid blue" : "2px dashed gray",
      padding: 24,
    }}
  >
    <p>{isOver ? "Release to drop files" : "Drag images or PDFs here"}</p>
    {files && <p>{files.length} file(s) selected</p>}
  </div>
)
```

### Attaching to an Existing `RefObject`

Pass `target` in the options object to attach drag listeners directly to an existing element ref.

```tsx
const dropRef = useRef<HTMLDivElement>(null)

const { isOver, clearFiles } = useDropZone({
  target: dropRef,
  accept: ".csv",
  multiple: false,
})

return (
  <div ref={dropRef}>
    <p>{isOver ? "Drop CSV file" : "Drop a single CSV file here"}</p>
    <button onClick={clearFiles}>Reset</button>
  </div>
)
```
