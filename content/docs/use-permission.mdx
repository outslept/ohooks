<HookPreview name="usePermission" />

The `usePermission` hook queries `navigator.permissions.query` for a given permission name or descriptor and subscribes to live `PermissionStatus` changes (`'granted'`, `'denied'`, `'prompt'`, `'loading'`, or `'unsupported'`).

## Installation

<HookInstallation name="usePermission" />

## Usage

```tsx
import { usePermission } from "@/hooks/usePermission";
```

```tsx
const cameraPermission = usePermission("camera");
```

## Examples

### Checking Microphone or Geolocation Access

Render contextual onboarding UI depending on whether the permission is `'prompt'`, `'granted'`, or `'denied'`.

```tsx
const state = usePermission("geolocation");

if (state === "loading") return <p>Checking permission...</p>;
if (state === "denied") {
  return <p>Location access is blocked in your browser settings.</p>;
}

return <p>Geolocation permission status: {state}</p>;
```

### Passing an Extended Permission Descriptor

Pass a descriptor object when querying permissions with extra options such as ` midi` (`sysex: true`).

```tsx
const midiState = usePermission({ name: "midi", sysex: true });

return <p>MIDI SysEx access: {midiState}</p>;
```
