The `useRovingTabIndex` hook implements the WAI-ARIA roving `tabIndex` pattern for toolbars, tablists, menus, and radio groups, managing arrow-key navigation, `Home`/`End` shortcuts, looping, disabled item skipping, and DOM focus synchronization.

## Installation

<HookInstallation name="useRovingTabIndex" />

## Usage

```tsx
import { useRovingTabIndex } from "@/hooks/useRovingTabIndex";
```

```tsx
const { getItemProps } = useRovingTabIndex({ orientation: "horizontal" });

return (
  <div role="toolbar">
    {items.map((item, i) => (
      <button key={item.id} {...getItemProps(i)}>
        {item.label}
      </button>
    ))}
  </div>
);
```

## Examples

### Horizontal Toolbar with Disabled Items

Pass `{ disabled: true }` to `getItemProps` so arrow keys automatically skip disabled buttons while navigating.

```tsx
const { activeIndex, getItemProps } = useRovingTabIndex({
  orientation: "horizontal",
  loop: true,
});

const actions = [
  { label: "Cut", disabled: false },
  { label: "Copy", disabled: false },
  { label: "Paste", disabled: true },
  { label: "Delete", disabled: false },
];

return (
  <div role="toolbar" aria-label="Text actions">
    {actions.map((action, index) => (
      <button
        key={action.label}
        disabled={action.disabled}
        {...getItemProps(index, { disabled: action.disabled })}
      >
        {action.label} {activeIndex === index ? "(Focused)" : ""}
      </button>
    ))}
  </div>
);
```

### Vertical Menu List

Set `orientation: "vertical"` to navigate items using `ArrowUp` and `ArrowDown`.

```tsx
const { getItemProps, focusItem } = useRovingTabIndex({
  orientation: "vertical",
  defaultIndex: 0,
});

return (
  <div>
    <button onClick={() => focusItem(2)}>Jump to item 3</button>
    <ul role="menu">
      {["Profile", "Billing", "Team", "Log out"].map((label, index) => (
        <li key={label} role="none">
          <button role="menuitem" {...getItemProps(index)}>
            {label}
          </button>
        </li>
      ))}
    </ul>
  </div>
);
```
