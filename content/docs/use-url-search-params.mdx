The `useUrlSearchParams` hook reads `window.location.search` via `useSyncExternalStore` and returns a `[searchParams, setSearchParams]` tuple that updates the URL using `history.pushState` or `history.replaceState` while notifying all subscribed components.

## Installation

<HookInstallation name="useUrlSearchParams" />

## Usage

```tsx
import { useUrlSearchParams } from "@/hooks/useUrlSearchParams"
```

```tsx
const [searchParams, setSearchParams] = useUrlSearchParams()
const query = searchParams.get("q") ?? ""
```

## Examples

### Updating Query Parameters with an Object or Functional Updater

Pass a plain object (where `null` or `undefined` removes a parameter) or an updater function that mutates a cloned `URLSearchParams` instance.

```tsx
const [searchParams, setSearchParams] = useUrlSearchParams()
const sort = searchParams.get("sort") ?? "newest"

return (
  <div>
    <p>Current sort: {sort}</p>
    <button
      onClick={() =>
        setSearchParams((prev) => {
          prev.set("sort", "popular")
          return prev
        })
      }
    >
      Sort by popular
    </button>
    <button onClick={() => setSearchParams({ sort: null })}>
      Clear sort
    </button>
  </div>
)
```

### Pushing vs. Replacing History Entries

By default, updates use `replaceState` so rapid filter changes do not clutter browser history; pass `{ history: "push" }` when you want the Back button to undo the change.

```tsx
const [searchParams, setSearchParams] = useUrlSearchParams({
  history: "replace",
})

return (
  <button
    onClick={() =>
      setSearchParams({ tab: "billing" }, { history: "push" })
    }
  >
    Open Billing tab
  </button>
)
```
