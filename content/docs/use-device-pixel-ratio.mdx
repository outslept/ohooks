The `useDevicePixelRatio` hook tracks `window.devicePixelRatio` using `useSyncExternalStore` and dynamic `(resolution: ...dppx)` media queries so components update automatically when the window moves between displays or the browser zoom level changes.

## Installation

<HookInstallation name="useDevicePixelRatio" />

## Usage

```tsx
import { useDevicePixelRatio } from "@/hooks/useDevicePixelRatio";
```

```tsx
const dpr = useDevicePixelRatio({ defaultValue: 1 });
```

## Examples

### Scaling an HTML Canvas for Retina Displays

Multiply the canvas backing store dimensions by `dpr` so drawings stay crisp on high-DPI screens.

```tsx
const dpr = useDevicePixelRatio();
const width = 300;
const height = 150;

return <canvas width={width * dpr} height={height * dpr} style={{ width, height }} />;
```

### Selecting High-Resolution Assets

Use `dpr` to pick appropriately scaled image URLs or icons based on the active screen density.

```tsx
const dpr = useDevicePixelRatio({ defaultValue: 1 });
const suffix = dpr >= 2 ? "@2x" : "";

return <img src={`/images/logo${suffix}.png`} alt="Logo" />;
```
