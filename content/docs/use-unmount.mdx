<HookPreview name="useUnmount" />

The `useUnmount` hook runs a callback when the component unmounts from the DOM, reading the latest props and state via `useLatest` so your cleanup logic never suffers from stale closures.

## Installation

<HookInstallation name="useUnmount" />

## Usage

```tsx
import { useUnmount } from "@/hooks/useUnmount"
```

```tsx
useUnmount(() => {
  analytics.trackExit(latestStep)
})
```

## Examples

### Saving Unsaved Draft State on Unmount

Persist the latest form input value when the user navigates away and unmounts the component.

```tsx
const [draft, setDraft] = useState("")

useUnmount(() => {
  if (draft.trim()) {
    localStorage.setItem("unsaved-draft", draft)
  }
})

return (
  <textarea
    value={draft}
    onChange={(e) => setDraft(e.target.value)}
    placeholder="Type a note..."
  />
)
```

### Reporting Analytics View Duration

Record how far the user progressed before closing a view.

```tsx
const [completedSteps, setCompletedSteps] = useState(1)

useUnmount(() => {
  sendTelemetry({ event: "wizard_closed", completedSteps })
})
```
