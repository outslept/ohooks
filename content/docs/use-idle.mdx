<HookPreview name="useIdle" />

The `useIdle` hook monitors user activity across mouse, pointer, touch, keyboard, wheel, and visibility events and returns `true` when no interaction has occurred for `timeout` milliseconds.

## Installation

<HookInstallation name="useIdle" />

## Usage

```tsx
import { useIdle } from "@/hooks/useIdle";
```

```tsx
const isIdle = useIdle(30_000);
```

## Examples

### Auto-Locking a Session After Inactivity

Detect when the user has been inactive for 60 seconds and show a lock screen or warning banner.

```tsx
const isIdle = useIdle(60_000);

return (
  <div>
    <p>Status: {isIdle ? "Away" : "Active"}</p>
    {isIdle && <div role="alert">Session paused due to inactivity.</div>}
  </div>
);
```

### Custom Activity Events and Initial State

Customize the list of DOM events that reset the timer or start in the idle state using `initialState`.

```tsx
const isIdle = useIdle(10_000, {
  initialState: false,
  events: ["keydown", "pointerdown"],
});
```
