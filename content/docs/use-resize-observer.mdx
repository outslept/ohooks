The `useResizeObserver` hook observes a target DOM element via `ResizeObserver`, returns the latest `ResizeObserverEntry` (or invokes a custom `onResize` callback without triggering state updates), and cleans up automatically on unmount.

## Installation

<HookInstallation name="useResizeObserver" />

## Usage

```tsx
import { useResizeObserver } from "@/hooks/useResizeObserver";
```

```tsx
const boxRef = useRef<HTMLDivElement>(null);
useResizeObserver(boxRef, (entry) => {
  console.log(entry.contentRect.width);
});
```

## Examples

### Reading the Returned `ResizeObserverEntry`

Omit the callback argument (or pass an options object as the second argument) to read the reactive `ResizeObserverEntry` directly from the return value.

```tsx
const panelRef = useRef<HTMLDivElement>(null);
const entry = useResizeObserver(panelRef, { box: "content-box" });

const width = entry?.contentRect.width ?? 0;
const height = entry?.contentRect.height ?? 0;

return (
  <div ref={panelRef}>
    Size: {Math.round(width)}px × {Math.round(height)}px
  </div>
);
```

### Callback-Only Mode for Imperative Updates

Pass a callback function as the second argument to handle resize events imperatively (such as resizing a chart or canvas) without re-rendering the component on every pixel change.

```tsx
const canvasContainerRef = useRef<HTMLDivElement>(null);

useResizeObserver(
  canvasContainerRef,
  (entry) => {
    resizeChartInstance(entry.contentRect.width, entry.contentRect.height);
  },
  { box: "border-box" },
);

return <div ref={canvasContainerRef} />;
```
