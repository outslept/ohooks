<HookPreview name="useWindowScroll" />

The `useWindowScroll` hook tracks `window.scrollX` and `window.scrollY` with passive event listeners (optional `throttleMs`), and provides a programmatic `scrollTo` helper.

## Installation

<HookInstallation name="useWindowScroll" />

## Usage

```tsx
import { useWindowScroll } from "@/hooks/useWindowScroll";
```

```tsx
const { y, scrollTo } = useWindowScroll({ throttleMs: 50 });
```

## Examples

### Floating "Back to Top" Button

Show a button once the user scrolls past `300px` vertically and smoothly scroll back to the top on click.

```tsx
const { y, scrollTo } = useWindowScroll();

return (
  <div>
    <p>Scrolled: {Math.round(y)}px</p>
    {y > 300 && (
      <button onClick={() => scrollTo({ top: 0, behavior: "smooth" })}>Back to top</button>
    )}
  </div>
);
```

### Throttling Scroll Updates

Set `throttleMs` to reduce the frequency of state updates during fast scrolling.

```tsx
const { x, y } = useWindowScroll({
  throttleMs: 100,
  initialPosition: { x: 0, y: 0 },
});
```
