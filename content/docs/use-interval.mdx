title: useInterval
description: Runs a callback repeatedly at a specified millisecond interval, pausing when delay is null.

<HookPreview name="useInterval" />

The `useInterval` hook executes a callback on a repeating timer and automatically pauses whenever `delay` is set to `null`, always invoking the latest callback without resetting the interval on every render.

## Installation

<HookInstallation name="useInterval" />

## Usage

```tsx
import { useInterval } from "@/hooks/useInterval";
```

```tsx
useInterval(
  () => {
    pollStatus();
  },
  isPolling ? 5000 : null,
);
```

## Examples

### Pausable Stopwatch

Pass `null` as the `delay` when paused so the interval is cleared until `isRunning` becomes `true` again.

```tsx
const [seconds, setSeconds] = useState(0);
const [isRunning, setIsRunning] = useState(true);

useInterval(
  () => {
    setSeconds((prev) => prev + 1);
  },
  isRunning ? 1000 : null,
);

return (
  <div>
    <p>Elapsed: {seconds}s</p>
    <button onClick={() => setIsRunning((prev) => !prev)}>{isRunning ? "Pause" : "Resume"}</button>
  </div>
);
```

### Dynamic Tick Speed

Update the `delay` value reactively to speed up or slow down the interval on the fly.

```tsx
const [delay, setDelay] = useState(1000);
const [ticks, setTicks] = useState(0);

useInterval(() => {
  setTicks((t) => t + 1);
}, delay);

return (
  <div>
    <p>Ticks: {ticks}</p>
    <button onClick={() => setDelay(250)}>Fast (250ms)</button>
    <button onClick={() => setDelay(1000)}>Normal (1000ms)</button>
  </div>
);
```
