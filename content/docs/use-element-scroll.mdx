<HookPreview name="useElementScroll" />

The `useElementScroll` hook monitors a scrollable element's `x` and `y` scroll offsets, active scrolling state, movement directions (`left`, `right`, `top`, `bottom`), and edge arrival flags (`arrived`), while providing a programmatic `scrollTo` helper.

## Installation

<HookInstallation name="useElementScroll" />

## Usage

```tsx
import { useElementScroll } from "@/hooks/useElementScroll";
```

```tsx
const { y, isScrolling, arrived, scrollTo } = useElementScroll(containerRef);
```

## Examples

### Infinite Scroll Container

Check `arrived.bottom` together with an `offset.bottom` threshold to load more items when the user nears the bottom of a list.

```tsx
const listRef = useRef<HTMLDivElement>(null);
const { arrived } = useElementScroll(listRef, {
  offset: { bottom: 40 },
});

useEffect(() => {
  if (arrived.bottom) {
    loadNextPage();
  }
}, [arrived.bottom]);

return <div ref={listRef} style={{ height: 320, overflowY: "auto" }}></div>;
```

### Scroll-to-Top Button inside a Container

Use `y` to show a button after scrolling down and `scrollTo` to smoothly return to the top.

```tsx
const containerRef = useRef<HTMLDivElement>(null);
const { y, scrollTo } = useElementScroll(containerRef, {
  behavior: "smooth",
});

return (
  <div>
    <div ref={containerRef} style={{ height: 240, overflowY: "auto" }}></div>
    {y > 100 && <button onClick={() => scrollTo({ y: 0 })}>Back to top</button>}
  </div>
);
```
