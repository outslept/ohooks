The `useCopyToClipboard` hook writes text to the system clipboard via the Clipboard API (with a legacy `execCommand('copy')` fallback), tracks the last copied string, and optionally resets `isCopied` after a timeout.

## Installation

<HookInstallation name="useCopyToClipboard" />

## Usage

```tsx
import { useCopyToClipboard } from "@/hooks/useCopyToClipboard";
```

```tsx
const { isCopied, copy } = useCopyToClipboard({ resetInterval: 2000 });
```

## Examples

### Copy Button with Temporary Feedback

Set `resetInterval` so `isCopied` automatically reverts to `false` after a few seconds.

```tsx
const { isCopied, copy } = useCopyToClipboard({ resetInterval: 2000 });

return (
  <button onClick={() => copy("npm install react")}>{isCopied ? "Copied!" : "Copy command"}</button>
);
```

### Handling Errors and Inspecting the Copied Value

Read `error` and `copiedText` or await the boolean promise returned by `copy` to trigger custom notifications.

```tsx
const { copiedText, error, copy, reset } = useCopyToClipboard();

return (
  <div>
    <button onClick={() => copy("https://example.com/invite")}>Copy invite link</button>
    {copiedText && (
      <p>
        Copied: <code>{copiedText}</code> <button onClick={reset}>Clear</button>
      </p>
    )}
    {error && <p role="alert">Failed to copy: {error.message}</p>}
  </div>
);
```
