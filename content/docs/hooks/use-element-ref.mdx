---
title: useElementRef
description: Provides a callback ref and reactive state for the mounted DOM element so effects re-run when the node attaches or detaches.
---

{/* Preview */}

The `useElementRef` hook returns a `[ref, element]` tuple where `ref` is a stable callback ref and `element` is the reactive DOM node state (`T | null`), ensuring effects and hooks re-run whenever a conditionally rendered element mounts or unmounts.

## Installation

<HookInstallation name="useElementRef" />

## Usage

```tsx
import { useElementRef } from "@/hooks/useElementRef"
```

```tsx
const [ref, element] = useElementRef<HTMLDivElement>()
```

## Examples

### Observing a Conditionally Rendered Element

Unlike `useRef`, `useElementRef` triggers a re-render when the node attaches so dependent `useEffect` hooks always receive the live element.

```tsx
const [open, setOpen] = useState(false)
const [panelRef, panelElement] = useElementRef<HTMLDivElement>()

useEffect(() => {
  if (!panelElement) return
  panelElement.focus()
}, [panelElement])

return (
  <div>
    <button onClick={() => setOpen((prev) => !prev)}>Toggle panel</button>
    {open && (
      <div ref={panelRef} tabIndex={-1}>
        Focusable panel
      </div>
    )}
  </div>
)
```

### Composing with Other DOM Hooks

Pass `element` directly to hooks or APIs that accept `Element | null` so subscriptions attach as soon as the node mounts.

```tsx
const [containerRef, container] = useElementRef<HTMLDivElement>()

return (
  <div ref={containerRef}>
    <p>Mounted: {container ? "Yes" : "No"}</p>
  </div>
)
```
