The `useScript` hook injects an external `<script>` tag into `document.body` (or attaches to an existing tag with the same `src`), deduplicates concurrent requests across multiple mounted components, and returns the current loading status (`'idle'`, `'loading'`, `'ready'`, or `'error'`).

## Installation

<HookInstallation name="useScript" />

## Usage

```tsx
import { useScript } from "@/hooks/useScript"
```

```tsx
const status = useScript("https://js.stripe.com/v3/")
```

## Examples

### Rendering a Widget Once the Script is `'ready'`

Check `status === "ready"` before initializing or rendering components that depend on the global script.

```tsx
const status = useScript("https://checkout.stripe.com/checkout.js")

if (status === "loading") return <p>Loading payment SDK...</p>
if (status === "error") return <p role="alert">Failed to load payment SDK.</p>

return <button disabled={status !== "ready"}>Pay now</button>
```

### Conditional Loading and Cleanup on Unmount

Pass `null` (or `shouldPreventLoad: true`) to defer loading until needed, and `removeOnUnmount: true` to remove the `<script>` tag when the last consumer unmounts.

```tsx
const [enabled, setEnabled] = useState(false)

const status = useScript(
  enabled ? "https://example.com/analytics.js" : null,
  {
    id: "custom-analytics",
    removeOnUnmount: true,
    attrs: { "data-site-id": "my-site" },
  }
)

return (
  <div>
    <button onClick={() => setEnabled(true)}>Enable analytics</button>
    <p>Script status: {status}</p>
  </div>
)
```
