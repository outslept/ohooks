The `useHash` hook reads `window.location.hash` (without the leading `#` character) and updates it reactively across the app via `useSyncExternalStore`.

## Installation

<HookInstallation name="useHash" />

## Usage

```tsx
import { useHash } from "@/hooks/useHash"
```

```tsx
const [hash, setHash] = useHash()
```

## Examples

### Hash-Based Tab Navigation

Sync the active tab with the URL hash so users can bookmark or share links to specific sections.

```tsx
const [hash, setHash] = useHash({ defaultValue: "overview" })
const activeTab = hash || "overview"

return (
  <div>
    <button onClick={() => setHash("overview")}>Overview</button>
    <button onClick={() => setHash("activity")}>Activity</button>
    <p>Current section: {activeTab}</p>
  </div>
)
```

### Replacing History Entries Instead of Pushing

Pass `{ replace: true }` as the second argument to `setHash` to update the URL hash via `history.replaceState` without creating a new browser history entry.

```tsx
const [hash, setHash] = useHash()

return (
  <div>
    <button onClick={() => setHash("step-2", { replace: true })}>
      Go to Step 2 (replace)
    </button>
    <button onClick={() => setHash("", { replace: true })}>Clear hash</button>
  </div>
)
```
