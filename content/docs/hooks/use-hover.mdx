<HookPreview name="useHover" />

The `useHover` hook tracks `pointerenter` and `pointerleave` events on a target DOM element and supports configurable `enterDelay` and `leaveDelay` timers.

## Installation

<HookInstallation name="useHover" />

## Usage

```tsx
import { useHover } from "@/hooks/useHover"
```

```tsx
const isHovered = useHover(cardRef, { enterDelay: 100, leaveDelay: 150 })
```
