The `usePointerDrag` hook tracks pointer drag gestures on a target element using `setPointerCapture` so dragging continues smoothly even when the pointer leaves the element bounds, supporting axis locking (`'x'`, `'y'`, or `'both'`) and activation distance thresholds.

## Installation

<HookInstallation name="usePointerDrag" />

## Usage

```tsx
import { usePointerDrag } from "@/hooks/usePointerDrag"
```

```tsx
const boxRef = useRef<HTMLDivElement>(null)
const { isDragging, deltaX, deltaY } = usePointerDrag(boxRef)
```

## Examples

### Draggable Card with Transform Offset

Translate an element by `deltaX` and `deltaY` while dragging and accumulate the final offset in `onDragEnd`.

```tsx
const boxRef = useRef<HTMLDivElement>(null)
const [offset, setOffset] = useState({ x: 0, y: 0 })

const { isDragging, deltaX, deltaY } = usePointerDrag(boxRef, {
  onDragEnd: (state) => {
    setOffset((prev) => ({
      x: prev.x + state.deltaX,
      y: prev.y + state.deltaY,
    }))
  },
})

const x = offset.x + (isDragging ? deltaX : 0)
const y = offset.y + (isDragging ? deltaY : 0)

return (
  <div
    ref={boxRef}
    style={{
      transform: `translate3d(${x}px, ${y}px, 0)`,
      cursor: isDragging ? "grabbing" : "grab",
    }}
  >
    Drag me
  </div>
)
```
