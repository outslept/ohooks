title: useFocusTrap
description: "Traps keyboard `Tab` / `Shift+Tab` focus within a container element and optionally restores focus on unmount."

## Usage

```tsx
useFocusTrap(modalRef, {
  enabled: isOpen,
  onEscape: () => setIsOpen(false),
});
```
