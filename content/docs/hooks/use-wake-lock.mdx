---
title: useWakeLock
description: Prevents the device screen from dimming or locking using the Screen Wake Lock API.
---

{/* Preview */}

The `useWakeLock` hook requests and releases a `'screen'` wake lock via `navigator.wakeLock.request('screen')`, and automatically re-acquires the lock when the tab returns to `'visible'` after being backgrounded.

## Installation

<HookInstallation name="useWakeLock" />

## Usage

```tsx
import { useWakeLock } from "@/hooks/useWakeLock"
```

```tsx
const { isLocked, isSupported } = useWakeLock(isPlayingVideo)
```

## Examples

### Declarative Wake Lock Tied to Playback State

Pass a boolean as the first argument to automatically acquire the wake lock when `isPlaying` is `true` and release it when `false`.

```tsx
const [isPlaying, setIsPlaying] = useState(false)
const { isLocked, isSupported } = useWakeLock(isPlaying)

return (
  <div>
    <button onClick={() => setIsPlaying((p) => !p)}>
      {isPlaying ? "Pause workout" : "Start workout"}
    </button>
    {isSupported && <p>Screen lock prevented: {isLocked ? "Yes" : "No"}</p>}
  </div>
)
```

### Imperative `request` and `release` Controls

Omit the boolean argument and use `request()` and `release()` directly with error and release callbacks.

```tsx
const { isLocked, request, release, error } = useWakeLock({
  reacquireOnPageVisible: true,
  onError: (err) => console.warn("Wake lock error:", err),
})

return (
  <div>
    <button onClick={isLocked ? release : request}>
      {isLocked ? "Allow screen sleep" : "Keep screen awake"}
    </button>
    {error && <p role="alert">{error.message}</p>}
  </div>
)
```
