The `useAnimationFrame` hook runs a callback on every `requestAnimationFrame` tick, providing frame timing metadata (`timestamp`, `deltaTime`, `elapsedTime`), optional FPS throttling, and imperative playback controls.

## Installation

<HookInstallation name="useAnimationFrame" />

## Usage

```tsx
import { useAnimationFrame } from "@/hooks/useAnimationFrame"
```

```tsx
const { isActive, start, stop, toggle } = useAnimationFrame(
  ({ deltaTime, elapsedTime }) => {
    updatePosition(deltaTime)
  }
)
```

## Features

- Automatic `requestAnimationFrame` loop cleanup on unmount
- Frame timing metadata (`timestamp`, `deltaTime`, and total `elapsedTime`)
- Optional `fpsLimit` to throttle execution without drift
- Imperative `start`, `stop`, and `toggle` controls with reactive `isActive` state
- Always invokes the latest callback without restarting the animation loop

## Examples

### FPS Limiting

Use `fpsLimit` to cap how often the callback runs per second while keeping smooth frame pacing.

```tsx
useAnimationFrame(
  ({ deltaTime }) => {
    renderCanvas(deltaTime)
  },
  { fpsLimit: 30 }
)
```

### Manual Start

Set `immediate: false` to keep the loop paused on mount and start it on user interaction.

```tsx
const { isActive, toggle } = useAnimationFrame(
  ({ elapsedTime }) => {
    setProgress(elapsedTime)
  },
  { immediate: false }
)
```
