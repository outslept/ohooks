The `useDebounceValue` hook delays updates to a reactive value until `delay` milliseconds have passed without further changes, returning a tuple of the debounced value and the underlying debounced setter function.

## Installation

<HookInstallation name="useDebounceValue" />

## Usage

```tsx
import { useDebounceValue } from "@/hooks/useDebounceValue"
```

```tsx
const [debouncedQuery, setDebouncedQuery] = useDebounceValue(searchQuery, 300)
```

## Examples

### Filtering a Search Input

Pass a rapidly changing input state to `useDebounceValue` so expensive filtering or network requests only run after the user pauses typing.

```tsx
const [query, setQuery] = useState("")
const [debouncedQuery] = useDebounceValue(query, 300)

useEffect(() => {
  if (debouncedQuery) {
    fetchSearchResults(debouncedQuery)
  }
}, [debouncedQuery])

return (
  <input
    value={query}
    onChange={(e) => setQuery(e.target.value)}
    placeholder="Search..."
  />
)
```

### Flushing or Cancelling via the Setter

Use the second tuple item to manually update, flush, or cancel pending value transitions.

```tsx
const [text, setText] = useState("")
const [debouncedText, updateDebouncedText] = useDebounceValue(text, 500, {
  maxWait: 2000,
})

return (
  <div>
    <input value={text} onChange={(e) => setText(e.target.value)} />
    <button onClick={() => updateDebouncedText.flush()}>Apply now</button>
    <button onClick={() => updateDebouncedText.cancel()}>Cancel</button>
    <p>Debounced value: {debouncedText}</p>
  </div>
)
```
