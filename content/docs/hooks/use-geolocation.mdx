The `useGeolocation` hook subscribes to device position updates via `navigator.geolocation.watchPosition` and returns live coordinates, accuracy metrics, loading status, and error state.

## Installation

<HookInstallation name="useGeolocation" />

## Usage

```tsx
import { useGeolocation } from "@/hooks/useGeolocation"
```

```tsx
const { latitude, longitude, loading, error } = useGeolocation({
  enableHighAccuracy: true,
})
```

## Examples

### Displaying Live Coordinates

Render a loading indicator until the browser resolves the first position fix, and handle permission errors gracefully.

```tsx
const { latitude, longitude, accuracy, loading, error } = useGeolocation()

if (loading) return <p>Locating...</p>
if (error) return <p role="alert">Error: {error.message}</p>

return (
  <p>
    Position: {latitude?.toFixed(4)}, {longitude?.toFixed(4)} (±{accuracy}m)
  </p>
)
```

### Conditional Location Tracking (`enabled`)

Set `enabled: false` until the user explicitly opts in so the browser does not prompt for location permission on page load.

```tsx
const [tracking, setTracking] = useState(false)
const { latitude, longitude } = useGeolocation({
  enabled: tracking,
  enableHighAccuracy: true,
  maximumAge: 10_000,
})

return (
  <div>
    <button onClick={() => setTracking((prev) => !prev)}>
      {tracking ? "Stop tracking" : "Share my location"}
    </button>
    {latitude !== null && (
      <p>
        {latitude}, {longitude}
      </p>
    )}
  </div>
)
```
