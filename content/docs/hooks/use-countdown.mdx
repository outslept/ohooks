title: useCountdown

{/* Preview */}

The `useCountdown` hook steps a numeric counter toward a target value on a fixed interval and provides `start`, `pause`, and `reset` controls along with a completion callback.

## Installation

<HookInstallation name="useCountdown" />

## Usage

```tsx
import { useCountdown } from "@/hooks/useCountdown"
```

```tsx
const { count, isRunning, start, pause, reset } = useCountdown({
  countStart: 60,
  countStop: 0,
  intervalMs: 1000,
})
```

## Examples

### Resend Verification Code Timer

Use `onComplete` to unlock an action when the countdown reaches `countStop`, and call `reset` followed by `start` to restart the timer.

```tsx
const [canResend, setCanResend] = useState(false)

const { count, start, reset } = useCountdown({
  countStart: 30,
  countStop: 0,
  intervalMs: 1000,
  onComplete: () => setCanResend(true),
})

const handleResend = () => {
  setCanResend(false)
  reset()
  start()
}

return (
  <button onClick={handleResend} disabled={!canResend}>
    {canResend ? "Resend code" : `Resend in ${count}s`}
  </button>
)
```

### Count-Up Timer

Set `isIncrement: true` and a higher `countStop` to count upward instead of downward.

```tsx
const { count, isRunning, start, pause, reset } = useCountdown({
  countStart: 0,
  countStop: 100,
  intervalMs: 100,
  isIncrement: true,
})

return (
  <div>
    <p>Progress: {count}%</p>
    <button onClick={isRunning ? pause : start}>
      {isRunning ? "Pause" : "Start"}
    </button>
    <button onClick={reset}>Reset</button>
  </div>
)
```
