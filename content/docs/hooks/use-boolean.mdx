The `useBoolean` hook manages a boolean state and provides memoized helper callbacks (`setTrue`, `setFalse`, `toggle`, and `setValue`) for common state transitions.

## Installation

<HookInstallation name="useBoolean" />

## Usage

```tsx
import { useBoolean } from "@/hooks/useBoolean"
```

```tsx
const { value, setTrue, setFalse, toggle } = useBoolean(false)
```

## Examples

### Controlling a Dialog

Use `setTrue` and `setFalse` directly as event handlers without creating inline arrow functions.

```tsx
const { value: isOpen, setTrue: open, setFalse: close } = useBoolean(false)

return (
  <>
    <button onClick={open}>Open dialog</button>
    {isOpen && (
      <div role="dialog">
        <p>Dialog content</p>
        <button onClick={close}>Close</button>
      </div>
    )}
  </>
)
```

### Toggling State

Use `toggle` to flip the current boolean value, or `setValue` when you need to pass an explicit boolean.

```tsx
const { value: isMuted, toggle, setValue } = useBoolean(false)

return (
  <div>
    <button onClick={toggle}>{isMuted ? "Unmute" : "Mute"}</button>
    <button onClick={() => setValue(false)}>Reset sound</button>
  </div>
)
```
