title: useObjectUrl
description: Creates a temporary object URL (URL.createObjectURL) for a Blob, File, or MediaSource and automatically revokes it on change or unmount.
---

<HookPreview name="useObjectUrl" />

The `useObjectUrl` hook generates a `blob:` URL via `URL.createObjectURL` whenever a `Blob`, `File`, or `MediaSource` is provided and automatically calls `URL.revokeObjectURL` when the input changes or the component unmounts to prevent memory leaks.

## Installation

<HookInstallation name="useObjectUrl" />

## Usage

```tsx
import { useObjectUrl } from "@/hooks/useObjectUrl"
```

```tsx
const previewUrl = useObjectUrl(selectedFile)
```

## Examples

### Instant Image Upload Preview

Pass a selected `File` from an `<input type="file">` to preview the image before uploading it to a server.

```tsx
const [file, setFile] = useState<File | null>(null)
const previewUrl = useObjectUrl(file)

return (
  <div>
    <input
      type="file"
      accept="image/*"
      onChange={(e) => setFile(e.target.files?.[0] ?? null)}
    />
    {previewUrl && <img src={previewUrl} alt="Selected preview" width={200} />}
  </div>
)
```

### Downloadable Dynamically Generated `Blob`

Create a `Blob` in memory and pass it to `useObjectUrl` to power a client-side download link.

```tsx
const csvBlob = useMemo(
  () => new Blob(["id,name\n1,Alice\n2,Bob"], { type: "text/csv" }),
  []
)
const downloadUrl = useObjectUrl(csvBlob)

return (
  <a href={downloadUrl ?? undefined} download="users.csv">
    Download CSV
  </a>
)
```
