title: useVirtualList

The `useVirtualList` hook virtualizes large lists of fixed or variable-height items by observing scroll position and container height, rendering only the visible slice (plus configurable `overscan` rows) and providing a `scrollToIndex` helper.

## Installation

<HookInstallation name="useVirtualList" />

## Usage

```tsx
import { useVirtualList } from "@/hooks/useVirtualList"
```

```tsx
const containerRef = useRef<HTMLDivElement>(null)
const { virtualItems, wrapperProps } = useVirtualList(rows, {
  containerTarget: containerRef,
  itemHeight: 40,
})
```

## Examples

### Fixed-Height Virtualized List (`10,000` Rows)

Spread `wrapperProps` onto an inner wrapper element and position each virtual item at `offsetTop`.

```tsx
const containerRef = useRef<HTMLDivElement>(null)
const items = useMemo(
  () => Array.from({ length: 10_000 }, (_, i) => `Row #${i + 1}`),
  []
)

const { virtualItems, wrapperProps, scrollToIndex } = useVirtualList(items, {
  containerTarget: containerRef,
  itemHeight: 36,
  overscan: 5,
})

return (
  <div>
    <button onClick={() => scrollToIndex(5000, "center")}>
      Jump to Row #5001
    </button>
    <div
      ref={containerRef}
      style={{ height: 320, overflowY: "auto", border: "1px solid #ccc" }}
    >
      <div {...wrapperProps}>
        {virtualItems.map(({ index, data, offsetTop, height }) => (
          <div
            key={index}
            style={{
              position: "absolute",
              top: offsetTop,
              left: 0,
              right: 0,
              height,
            }}
          >
            {data}
          </div>
        ))}
      </div>
    </div>
  </div>
)
```

### Variable-Height Rows

Pass a function `(index, item) => number` as `itemHeight` to compute dynamic row heights using binary search.

```tsx
const { virtualItems, wrapperProps } = useVirtualList(messages, {
  containerTarget: containerRef,
  itemHeight: (index, msg) => (msg.isExpanded ? 120 : 48),
  overscan: 3,
})
```
