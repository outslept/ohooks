title: usePreferredLanguage
description: Tracks the user's preferred browser language (navigator.language) and updates on changes.
---

{/* Preview */}

The `usePreferredLanguage` hook reads `navigator.language` and subscribes to the window `languagechange` event via `useSyncExternalStore` so localized formatting updates immediately if the user changes their browser language preferences.

## Installation

<HookInstallation name="usePreferredLanguage" />

## Usage

```tsx
import { usePreferredLanguage } from "@/hooks/usePreferredLanguage"
```

```tsx
const language = usePreferredLanguage("en-US")
```

## Examples

### Formatting Dates and Currency with `Intl`

Pass the detected BCP 47 language tag to `Intl.DateTimeFormat` or `Intl.NumberFormat`.

```tsx
const locale = usePreferredLanguage("en-US")

const formattedPrice = new Intl.NumberFormat(locale, {
  style: "currency",
  currency: "USD",
}).format(1299.5)

return (
  <p>
    Locale ({locale}): {formattedPrice}
  </p>
)
```

### Custom SSR Fallback Locale

Provide a `defaultValue` matching your server's default locale to prevent hydration mismatches.

```tsx
const locale = usePreferredLanguage("de-DE")

return <p>Preferred language: {locale}</p>
```
