title: useSpinDelay

{/* Preview */}

The `useSpinDelay` hook smooths loading states by waiting `delay` milliseconds before returning `true` (so fast requests under the threshold never show a spinner) and keeping the spinner visible for at least `minDuration` milliseconds once shown to avoid jarring flickers.

## Installation

<HookInstallation name="useSpinDelay" />

## Usage

```tsx
import { useSpinDelay } from "@/hooks/useSpinDelay"
```

```tsx
const showSpinner = useSpinDelay(isFetching, { delay: 400, minDuration: 200 })
```

## Examples

### Preventing Spinner Flash on Fast Network Requests

Wrap your `isLoading` boolean with `useSpinDelay` before rendering a skeleton or spinner.

```tsx
const [isLoading, setIsLoading] = useState(false)
const showSpinner = useSpinDelay(isLoading, {
  delay: 300,
  minDuration: 400,
})

return (
  <div>
    <button onClick={() => setIsLoading((prev) => !prev)}>
      Toggle loading
    </button>
    {showSpinner ? <p>Loading data...</p> : <p>Content ready</p>}
  </div>
)
```

### Customizing Thresholds for Instant Feedback vs. Background Sync

Use a shorter `delay` and longer `minDuration` for primary page transitions so the loading skeleton feels intentional once triggered.

```tsx
const showOverlay = useSpinDelay(isSaving, {
  delay: 150,
  minDuration: 500,
})
```
